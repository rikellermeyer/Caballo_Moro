# Candidate gene selection

## Data sources / Input
Input for candidate gene intersection (`candidate_intersect.py`) must be a list of genes only for each data source.
Two options for .gtf file to annotate regions: `genome/genes_and_pos.Amex3.0_surface.txt` (best option, tab separated, unique genes with full bp range) or `genome/gtf_genes_only.csv` (worse option, comma separated, not unique)

### GWAS
- Origin: GWAS of Caballo Moro cave generated by `../popgen/gwasfixandtest.py` to `data/popgen/gwas/tests/CA_trend.model` 
- Processing: Filtered to Cochran-Armitage trend test p-value<1e-9. Generated via `filter_gwas.sh`: `data/candidate_genes/CA_trend.filtered.tsv`. Compared to .gtf for annotation via `gwas_to_gtf.py`. 
- Input file: `data/candidate_genes/GWAS/GWAS_genes_only.txt`

### Genotype Filtering
- Origin: Variants were filtered & intersected by genotype with `genotype_filter.py`: Eyeless = Alternate/Alternate (AA), Eyed = Reference/Alternate (R/A) or Reference/Reference (R/R), Surface = Reference/Reference (R/R)  with zero no-calls (no exclusions). Variants were annotated with SnpEff via `../variant_calling/snpeff_annotation.py` to `data/variant_calling/variants/geno_filter/eyeless_recessive/snpeff/eyeless_recessive.0nocalls.summary.genes.txt`
- Processing: Gene names were extracted from the summary file with a simple `awk | sort | uniq`
- Input file: `data_files/geno_filter_gene_id_only.txt`

### QTL Study
- Origin: [Wiese et al., 2024](https://doi.org/10.1093/jhered/esae040) consolidated *Astyanax mexicanus* QTLs generated by various studies into supplementary table 5, found in `data/candidate_gene_selection/original_QTL_analysis/wiese_qtl_supp5.csv`
- Processing: Eye-specific QTL regions were filtered to the terms found in `data_files/list_of_eye_qtl_traits.txt`, resulting in `data_files/eye_qtls_from_Wiese2024.csv`. QTL regions were then matched to genes identified in the reference genome .gtf file via `qtl_to_gtf.py`
- Input file: `genes_in_eye_qtls.txt`

### Selective Sweeps
- Origin: Genes under selective sweeps from [Moran et al., 2023](https://doi.org/10.1038/s41467-023-37909-8) obtained from [Dryad, `DryadData.Stat_by_gene_2023.xlsx`](https://doi.org/10.5061/dryad.3xsj3txmf)
- Processing: Dryad dataset was limited to select diplo output for each cave using a simple `awk` to `data/candidate_genes/sweeps/Moran_sweeps_supp.csv`, and filtered to hard or soft sweeps in at least one cave in `candidate_intersect.py`. Bonus file: `data/candidate_genes/sweeps/Moran_et_al_2023_sweeps_in_at_least_one_cave.tsv` for Supplementary Materials.
- Input file: `data/candidate_genes/sweeps/Moran_hard_and_soft_sweeps.csv`

### GO Terms
Input file: `data_files/ZF_DB_eye_genes.txt`: Database of zebrafish (D. rerio) eye genes pulled from Panther using the GO terms: eye, lens, optic, retina, sclera, vision, and visual.

## Annotating and comparing candidate genes
`gwas_to_gtf.py`: Annotating GWAS hits 
`qtl_to_gtf.py`: Annotating QTL matches
`candidate_intersect.py`: Takes the input of gene list from each data source and compares them. Output is `../../data/candidate_genes/`
1. Handles the processing of the Sweeps files from Moran et al.
2. Makes a database of all candidates + the origin of their candidacy: `geneID \t origin` to `list_of_all_candidate_genes.txt`
3. Finds unique genes per dataset: `unique_to_{group}.txt`
4. Finds genes shared between each pairwise dataset: `shared_{g1}v{g2}.txt`. Plots venn diagrams to `reports/candidate_genes_venn`
5. Finds genes that are shared between all datasets: `intersect_all.txt`
6. Outputs a summary file with the number of genes present in each: `Intersection_summary.txt`
